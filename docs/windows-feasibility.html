Recommended next build order

The order maximizes new evidence about Jev instead of adding more variants of text classification already demonstrated by email triage, sort, logs, and routing.

1 · Doom

Best stress test

It forces a clean split between slow semantic decisions and fast reflex control. Measure survival, action latency, stale-decision rate, cost, and a rule-controller baseline.

2 · Minecraft

Best hierarchical-agent test

It tests Astra planning, Jev action selection, recovery from failed actions, long-horizon state, and a visually inspectable world.

3 · X attention filter

Best product demonstration

It makes low-latency classification visible in a real interface. Build and test first against saved post fixtures; attach to a live feed only after the classifier is credible.

4 · Brain-dump router

Best personal utility

It turns spoken or pasted thoughts into structured destinations. The first version needs only text input and a local JSON export.

Decision

Doom should be next. It is now buildable without changing hardware, it probes a capability the existing repositories do not test, and its failure modes can be measured against a deterministic controller. CARLA and real-money trading should not be started on this machine.
